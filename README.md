# group4-bike-sharing-demand-prediction

AI3013 Machine Learning course project: hourly bike-sharing demand prediction and peak-imbalance warning using the UCI Bike Sharing Dataset and from-scratch Python models.

## Dataset
The dataset used in this project is the UCI Bike Sharing Dataset.

Dataset link:
https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

## Implementation
The models are implemented from scratch in Python using NumPy, Pandas, and Matplotlib only.

Implemented models:
- Ridge Linear Regression with Gradient Descent
- KNN Regression
- CART Regression Tree
- Gradient Boosting Regression Trees

python run_project.py
